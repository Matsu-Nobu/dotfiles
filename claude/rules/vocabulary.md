# 避ける語

このファイルには、書き言葉で使うと読み手に違和感を与える語と、その代わりに使う語の対応表を置く。この表は、`~/.claude/CLAUDE.md` の説明の原則「一般に知られている平易な語彙で書き、符号や造語を発明しない」を、個々の語に当てはめたものである。Claude は、対話応答・チケット・PR・ドキュメント・コードコメントを書くとき、表の左の列の語を使わず、右の列の語を使う。

## 対象にする語

表に載せるのは、動詞の連用形をそのまま名詞にした語（「確かめ」「欠け」）と、連用形に「方」を付けた語（「見せ方」「分け方」）のうち、同じ意味の漢語が仕様書や新聞のような書き言葉でふつうに使われているものである。

「書き方」「読み手」「言い換え」は載せない。同じ意味の漢語（「記法」「読者」「換言」）は意味が狭いか、書き言葉でもあまり使われないからである。動詞として使う形（「確かめる」「欠けている」）も載せない。ただし、ユーザーが意味の広さを指摘した和語の動詞（「出す」「書く」）は、どの意味のときに置き換えるかを限って載せる。

表に無い語でも、同じ形の語で、仕様書や新聞なら漢語を使う場面では、Claude は漢語を使う。ユーザーがある語を不自然だと指摘したときは、Claude は CLAUDE.md に規則を足さず、その語と代わりの漢語をこの表に 1 行足す。代わりの漢語は Claude が案を出し、ユーザーの承認を得て決める。

## 対応表

| 避ける語 | 代わりに使う語 | 書き換えの例 |
| --- | --- | --- |
| 確かめ | 確認 | 「送る前の確かめ」→「送る前の確認」 |
| 確かめ方 | 確認の手順 | 「送る前の確かめ方」→「送る前の確認の手順」 |
| 欠け | 不足（足りないとき）、欠落（丸ごと無いとき） | 「主語の欠け」→「主語の欠落」 |
| 決まり | 規則 | 「見せ方の決まり」→「体裁の規則」 |
| 見せ方 | 体裁 | 「見せ方の誤り」→「体裁の誤り」 |
| 書き直し | 改訂（規則や文書を新しい版にするとき）、修正（それ以外で誤りを直すとき） | 「説明の原則の書き直し」→「説明の原則の改訂」 |
| 組み立て | 構造（文の主語と述語の関係）、構成（それ以外の、節・手順・仕組みの並び） | 「文の組み立て」→「文の構造」 |
| 分け方 | 区分 | 「節の分け方」→「節の区分」 |
| 直し方 | 修正方法 | 「原因と直し方」→「原因と修正方法」 |
| ぶれ | ばらつき | 「採点のぶれ」→「採点のばらつき」 |
| 置き場所 | 配置 | 「表の置き場所」→「表の配置」 |
| 出す | 出力する（プログラムが画面・ファイル・別のプログラムに文字や値を送るとき）、表示する（画面に見せるとき） | 「バージョンを出す」→「バージョンを出力する」 |
| 書く（ファイルや設定に値を入れる意味のとき） | 記入する（値を入れる動作）、記載する（書かれている状態）、出力する（プログラムがファイル全体を作るとき） | 「`~/.gitconfig` に名前を書く」→「`~/.gitconfig` に名前を記入する」 |
| 作ったもの | 成果物 | 「作ったものの一覧」→「成果物の一覧」 |
